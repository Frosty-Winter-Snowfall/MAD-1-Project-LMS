# 📚 Library Management System (LMS)

Welcome to the **Library Management System (LMS)** project for **MAD 1**! This application is designed to streamline the management and use of library resources, offering an intuitive interface for both **Admin** and **Users**.

---

## ✨ Features

### Admin:
- **Sign Up/Login**: Admins can create accounts or log in to the system.
- **Manage Users**: Admins can add, update, or remove users.
- **Manage Books**: Admins can add, edit, or delete books in the system.
- **Manage Sections**: Admins can create, modify, and remove library sections.
- **View Statistics**: Admins have access to various statistics like book popularity and user activity.
- **Full Account Control**: Admins can edit their own profile and handle user feedback efficiently.

### User:
- **Sign Up/Login**: Users can create an account or log in to explore the library.
- **Borrow & Return Books**: Users can borrow and return books with a simple click.
- **Search**: Users can search for books or sections by title, author, or section name.
- **Give Feedback**: Users can leave feedback on books and the overall library experience.
- **Edit Profile**: Users can modify their personal information.
